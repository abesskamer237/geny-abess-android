# Geny-Abess Android

Application Android WebView pour https://geny.payool.net/.

## Générer l’APK avec GitHub Actions
1. Dans l’onglet **Actions**, choisissez **Build Geny-Abess APK** puis **Run workflow** (ou poussez sur `main`).
2. Une fois le job réussi, téléchargez l’artefact **Geny-Abess-debug-APK**.
3. Décompressez l’artefact et installez `app-debug.apk` sur Android.

APK debug signé automatiquement avec une clé de développement : adapté aux essais, pas à une distribution publique de production. Une connexion Internet est nécessaire.
